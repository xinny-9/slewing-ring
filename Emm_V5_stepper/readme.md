# Emm_V5.0 闭环步进电机驱动库 (STM32 HAL 库适配版)

本驱动库旨在为 STM32 HAL 平台提供一套完整、高效、高稳定性的 **Emm_V5.0/V5.1 闭环步进电机** 串口总线控制方案。库中不仅封装了电机的底层串口通信协议，更针对丝杆模组等典型应用，在应用层实现了物理距离与脉冲换算、软件行程防撞保护、上电自动温和堵转回零等一整套工业级最佳配置实践。

## 二、 核心功能与设计亮点

1. **HAL 库无缝适配**：
   抛弃了原厂例程中针对 STM32F1 标准外设库直接读写寄存器的陈旧写法，底层全部采用 HAL 库标准的 `HAL_UART_Transmit` 和 `HAL_UART_Receive`，保证了在新版本 CubeMX 生成的项目中可以直接拷贝并编译通过。
2. **双重状态接收机制**：
   * **阻塞式查询**：专门设计了 `Emm_V5_Read_Position_Blocking` 等函数。在发送查询指令后，在指定的 100ms 超时内通过 `HAL_UART_Receive` 同步等待响应并解算，适用于流程初始化等非高实时性场景。
   * **异步非阻塞解析**：提供了 `Emm_V5_Parse_Frame` 统一解析接口。若您在中断接收（单字节中断）或 DMA 接收（空闲中断断帧）中捕获到完整的数据包，直接传入该函数即可无延迟更新结构体状态，绝不占用 CPU 宝贵的等待时间。
3. **丝杆物理毫米级控制**：
   应用层 `app_stepper_ctrl` 完美屏蔽了电机旋转的脉冲运算。您只需输入丝杆导程（例如 8.0mm）与最大行程（例如 200.0mm），即可直接输入 `Stepper_App_MoveToPosition(50.0f, 1000)` 让滑块走到绝对的 50.0mm 坐标处，应用层会自动计算最短运行方向与所需的绝对脉冲。
4. **超低力矩温和堵转回零**：
   针对没有行程开关的丝杆模组，配置了最优参数以实现温和的堵转回零。回零速度降低至 `20 RPM`，堵转检测电流大幅压低至 `200 mA`，判定时间缩短为 `100 ms`。在回零寻零过程中，滑块碰到硬挡板（甚至用手指轻轻一挡）即可触发原点标定，避免了高扭矩死磕损坏机械结构。并在归零完成后自动朝反向避让 `4mm` 释放卡死应力。
5. **软行程限位拦截**：
   当应用层收到位置指令时，会首先校验目标物理位置是否在 `[0, 最大行程]` 范围内。一旦发生软件计算越界（如负数指令或超长距离），会直接拦截并拒绝执行，提供了双重防脱轨防撞墙的安全屏障。

## 三、 快速上手指南

### 1. 硬件连接
请确保 MCU 与电机控制板正确接线：
* MCU 的 **TX (发送)** $\rightarrow$ 电机驱动板的 **RX (接收)**
* MCU 的 **RX (接收)** $\rightarrow$ 电机驱动板的 **TX (发送)**
* **GND 共地**：STM32 的 GND 引脚必须与电机驱动板的 GND 引脚连通。
* 电机驱动板必须接入外部动力电源 (通常为 12V ~ 24V)。

### 2. 串口通信参数
在 STM32CubeMX 中配置与电机驱动板一致的参数 (可在电机的按键菜单中修改)：
* **波特率**：38400 或 115200 (需与电机菜单设置一致)
* **数据格式**：8 位数据位，1 位停止位，无校验 (8-N-1)

## 四、 核心 API 手册

### 1. 底层驱动层接口 (Emm_V5.h)

#### `void Emm_V5_Init(Emm_V5_Motor *motor, UART_HandleTypeDef *huart, uint8_t addr);`
* **功能**：初始化电机结构体，绑定串口外设和总线物理地址。
* **参数**：
  * `motor`：电机结构体变量指针。
  * `huart`：绑定的 HAL 串口句柄指针，例如 `&huart2`。
  * `addr``：电机的总线拨码地址 (1-255)。

#### `void Emm_V5_En_Control(Emm_V5_Motor *motor, bool state, bool snF);`
* **功能**：控制电机使能（线圈加电锁定）与失能（线圈断电释放）。

#### `void Emm_V5_Pos_Control(Emm_V5_Motor *motor, uint8_t dir, uint16_t vel, uint8_t acc, uint32_t clk, bool raF, bool snF);`
* **功能**：控制电机旋转到目标位置。
* **参数**：
  * `dir`：运行方向。`EMM_CW` (0) 或 `EMM_CCW` (1)。
  * `vel`：最大目标转速 (RPM，范围 0-5000)。
  * `acc`：加速度值 (0-255，0为直接启动)。
  * `clk`：目标脉冲数 (16细分下，3200个脉冲旋转一周)。
  * `raF`：`false`-相对位置模式；`true`-绝对位置模式 (推荐)。

#### `void Emm_V5_Reset_CurPos_To_Zero(Emm_V5_Motor *motor);`
* **功能**：将电机当前的物理位置，强制清零并设为软件上的绝对 0 坐标点。

#### `void Emm_V5_Modify_Subdivision(Emm_V5_Motor *motor, bool svF, uint8_t subdivide);`
* **功能**：修改电机的细分数。`subdivide` 常用值为 `16` (单圈3200脉冲) 和 `32` (单圈6400脉冲)。

---

### 2. 应用控制层接口 (app_stepper_ctrl.h)

#### `void Stepper_App_Init(UART_HandleTypeDef *huart, uint8_t addr);`
* **功能**：初始化丝杆应用控制层，绑定底层外设并自动配置温和碰撞回零参数。

#### `uint8_t Stepper_App_ExecuteHoming(void);`
* **功能**：触发温和堵转回零标定流程。电机将低速朝逆时针（CCW）撞墙，到位后标定零点，并自动反向避让 4mm，再次清零作为起始绝对位置基准。
* **返回值**：`1`-回零成功；`0`-回零超时或发生错误。

#### `uint8_t Stepper_App_MoveToPosition(float position_mm, uint16_t speed_rpm);`
* **功能**：以绝对物理距离控制丝杆向目标位置滑动。
* **参数**：
  * `position_mm`：目标绝对毫米位置 (范围 0.0 至 200.0mm)。
  * `speed_rpm`：运转最大限制转速 (RPM)。
* **返回值**：`1`-参数合法已执行；`0`-参数越界，拦截保护。

#### `float Stepper_App_GetCurrentPosition(void);`
* **功能**：阻塞式向电机读取当前真实的绝对物理坐标 (单位: mm)。如果读取出错返回 `-1.0f`。

## 五、 调试与常见问题排查

1. **无法建立通信**：
   * **共地**：检查 STM32 与电机的 GND 是否相连。
   * **接线交叉**：检查 RX 与 TX 是否接反。
   * **波特率**：检查电机屏幕上的波特率设置是否与 CubeMX 串口配置一致。
2. **回零时卡住一直顶死不退出**：
   * 表明电机没有触发堵转判定。可以尝试将检测电流阈值从 `200mA` 适当调小（例如 `170mA` 或 `180mA`，但不要低于电机的空载运动电流），或者确保丝杆两端的挡板足够坚固。
3. **回零没碰墙中途就误判断为到位**：
   * 表明丝杆轨道阻力过大或装配过紧。可以适当将检测电流阈值调大（如调至 `250mA` ~ `300mA`），或将判定时间延长（如 `150ms`），并给丝杆涂抹润滑油。
